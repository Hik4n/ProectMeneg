Выбор концепции программного проекта: TOPSIS и МАИ
Учебный проект по коллективной многокритериальной оценке и выбору концепции программного продукта.
В рамках первой фазы проекта рассматриваются четыре идеи программных продуктов. Для их сравнения используются два метода принятия решений: нечёткий TOPSIS и метод анализа иерархий (МАИ, AHP). Оценивание выполняется четырьмя экспертами.
Цель работы
Выбрать наиболее перспективную концепцию для дальнейшей разработки на основании экспертных оценок, заданных критериев и сопоставления результатов двух методов.

Критерии оценки
Конкурентоспособность — востребованность продукта и способность конкурировать с существующими решениями.
Простота реализации — сложность разработки и возможность создать работающий прототип.
Масштабируемость — потенциал расширения функциональности и увеличения нагрузки.
Потенциал монетизации — реалистичность получения дохода от продукта.
Используемые методы
Нечёткий TOPSIS
Эксперты оценивают каждую концепцию по четырём критериям. Лингвистические оценки переводятся в треугольные нечёткие числа:
Оценка	Треугольное нечёткое число
Низкий	(1, 3, 5)
Средний	(3, 5, 7)
Высокий	(5, 7, 9)
Этапы расчёта: сбор оценок четырёх экспертов, агрегирование, нормализация, взвешивание, определение положительного и отрицательного идеальных решений, вычисление расстояний и ранжирование альтернатив.
Относительная близость к идеальному решению:
$$
CC_i = \frac{d_i^-}{d_i^+ + d_i^-}
$$
где $d_i^+$ — расстояние до положительного идеального решения, а $d_i^-$ — до отрицательного. Чем выше $CC_i$, тем предпочтительнее концепция.
Метод анализа иерархий (МАИ / AHP)
Метод основан на попарных сравнениях критериев и альтернатив. По матрицам сравнений определяются локальные приоритеты, после чего рассчитывается итоговый приоритет каждой концепции с учётом весов критериев.

Результаты сравнения

Инструменты	0,642	2	0,1677	3

Оба метода определили «Карпулинг» как наиболее предпочтительную концепцию, а «Таск-трекер» — как наименее предпочтительную. Позиции «Гарантии» и «Инструментов» различаются из-за особенностей используемых методов: TOPSIS оценивает близость к идеальным решениям, а МАИ использует попарные предпочтения и веса критериев.
Выбранная концепция
Карпулинг — сервис поиска попутчиков и подбора поездок с учётом маршрутов и расписания.
По результатам первой фазы эта концепция выбрана для дальнейшей разработки. Решение обосновано совпадением первого места в рейтингах TOPSIS и МАИ.

Как ознакомиться с работой
Откройте `TOPSIS-MAI.xlsx` в Microsoft Excel или совместимом табличном редакторе.
Изучите листы с концепциями и экспертными оценками.
Перейдите к листам `TOPSIS` и `МАИ`, чтобы посмотреть расчёты.
Сопоставьте результаты на листе `Итог` с выводами в отчёте.
> **Примечание:** в заключительном абзаце исходного отчёта указано значение МАИ для «Карпулинга» 0,5258, тогда как в таблицах результатов отчёта — 0,4802. В этом README используется табличное значение 0,4802; расхождение необходимо проверить по расчётной книге.
