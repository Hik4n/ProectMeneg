# Выбор концепции программного проекта: TOPSIS и МАИ

Учебный проект по **коллективной многокритериальной оценке и выбору концепции программного продукта**.

В рамках первой фазы проекта рассматриваются четыре идеи программных продуктов. Для их сравнения используются два метода принятия решений: **нечёткий TOPSIS** и **метод анализа иерархий (МАИ, AHP)**. Оценивание выполняется четырьмя экспертами.

## Цель работы

Выбрать наиболее перспективную концепцию для дальнейшей разработки на основании экспертных оценок, заданных критериев и сопоставления результатов двух методов.

## Рассматриваемые концепции

| № | Концепция | Краткое название | Описание |
|---|---|---|---|
| 1 | Менеджер гарантийных сроков | Гарантия | Учёт покупок, гарантийных сроков и связанных документов |
| 2 | Сервис поиска попутчиков | Карпулинг | Поиск попутчиков и подбор поездок с учётом маршрутов и расписания |
| 3 | Сервис совместного использования инструментов | Инструменты | Поиск и организация совместного использования инструментов |
| 4 | Командный сервис с Kanban-доской | Таск-трекер | Организация задач команды и отслеживание их статусов |

## Критерии оценки

1. **Конкурентоспособность** — востребованность продукта и способность конкурировать с существующими решениями.
2. **Простота реализации** — сложность разработки и возможность создать работающий прототип.
3. **Масштабируемость** — потенциал расширения функциональности и увеличения нагрузки.
4. **Потенциал монетизации** — реалистичность получения дохода от продукта.

## Используемые методы

### Нечёткий TOPSIS

Эксперты оценивают каждую концепцию по четырём критериям. Лингвистические оценки переводятся в треугольные нечёткие числа:

| Критерий |
|---|---|
| Практическая полезность | 
| Простота реализации | 
| Удобство оценки и планирования | 
| Интерес команды |

Этапы расчёта: сбор оценок четырёх экспертов, агрегирование, нормализация, взвешивание, определение положительного и отрицательного идеальных решений, вычисление расстояний и ранжирование альтернатив.

Относительная близость к идеальному решению:

$$
CC_i = \frac{d_i^-}{d_i^+ + d_i^-}
$$

где $d_i^+$ — расстояние до положительного идеального решения, а $d_i^-$ — до отрицательного. Чем выше $CC_i$, тем предпочтительнее концепция.

### Метод анализа иерархий (МАИ / AHP)

Метод основан на попарных сравнениях критериев и альтернатив. По матрицам сравнений определяются локальные приоритеты, после чего рассчитывается итоговый приоритет каждой концепции с учётом весов критериев.

**Полученные веса критериев:**

| Критерий | Вес |
|---|---:|
| Конкурентоспособность | 44,91 % |
| Потенциал монетизации | 17,44 % |
| Масштабируемость | 26,44 % |
| Простота реализации | 11,21 % |

3. Перейдите к листам `TOPSIS` и `МАИ`, чтобы посмотреть расчёты.
4. Сопоставьте результаты на листе `Итог` с выводами в отчёте.
