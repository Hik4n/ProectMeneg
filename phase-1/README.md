## Критерии

| Код | Название | Направление | Что оцениваем |
|---|---|---|---|
| K1 | Практическая полезность | MAX | Польза приложения для выбранных пользователей |
| K2 | Простота реализации | MAX | Чем проще минимальная версия, тем выше оценка |
| K3 | Удобство оценки и планирования | MAX | Понятность сценариев, данных и задач для следующих фаз |
| K4 | Интерес команды | MAX | Интерес и знакомство участников с предметной областью |

## Параметры

| Параметр | Значение |
|---|---|
| Максимум шкалы TOPSIS | 9 |
| Порог согласованности CR | 0,1 |
| RI для матрицы 4 × 4 | 0,9 |

4 эксперта имеют одинаковый вес. TOPSIS: тройка MIN / MEDIAN / MAX.
